개인정보처리방침

시행일: 2026년 10월 3일

FotData(이하 "서비스")는 회원가입·로그인 없이 이용하는 무료 축구 분석 서비스입니다. 서비스는 이용자의 이름·연락처 같은 개인정보를 직접 수집하지 않으며, 서비스를 운영하는 데 필요한 최소한의 정보만 아래와 같이 처리합니다.

1. 직접 수집하는 개인정보

없습니다. 회원가입·로그인·결제 기능이 없고, 이름·이메일·전화번호 등을 입력받지 않습니다. 이용자가 문의 메일을 보내는 경우에만 회신을 위해 보낸 메일 주소와 내용을 처리하며, 문의 처리가 끝나면 지체 없이 삭제합니다.

2. 이용자 기기에만 저장되는 정보

편의 기능을 위해 아래 설정을 이용자의 브라우저 저장소(localStorage·sessionStorage)에만 저장합니다. 이 정보는 서버로 전송되지 않으며, 브라우저의 사이트 데이터 삭제로 언제든 지울 수 있습니다.

  • 즐겨찾기한 팀(최대 5팀), 첫 방문 안내 표시 여부
  • 화면 보기 설정(다음 경기 보기 방식, 테마), 랜딩 소개 애니메이션 재생 여부
  • 오프라인 실행을 위한 앱 화면 파일(서비스 워커 캐시)

서비스는 쿠키를 사용하지 않습니다.

3. 자동으로 생성되는 정보

  • 서버 접속 기록: 웹사이트·API를 제공하는 호스팅 사업자(Vercel, Render)가 보안과 장애 대응을 위해 접속 IP 주소, 접속 시각, 요청 주소, 브라우저 정보를 일시적으로 기록합니다. 보관 기간은 각 사업자의 정책을 따릅니다.
  • 방문 통계: 서비스 개선을 위해 쿠키를 쓰지 않는 방문 통계 도구(Umami)로 페이지 조회와 기능 사용 횟수(예: 경기 예측, 공유, 즐겨찾기 추가)를 익명으로 집계할 수 있습니다. 이 도구는 이용자를 식별하거나 다른 사이트에서 추적하지 않으며 IP 주소를 저장하지 않습니다.

4. 외부 서비스

화면을 보여주기 위해 아래 외부 서비스에서 파일을 불러오며, 이 과정에서 이용자의 IP 주소 등 접속 정보가 해당 사업자에게 전달될 수 있습니다(대부분 국외 사업자입니다).

5. 이용자의 권리

서비스가 보관하는 개인정보는 없으며, 기기에 저장된 설정은 브라우저 설정에서 사이트 데이터를 삭제하면 바로 지워집니다. 개인정보와 관련한 문의·열람·삭제 요청은 아래 연락처로 보내 주시면 지체 없이 처리합니다.

6. 아동의 개인정보

서비스는 개인정보를 수집하지 않으므로 만 14세 미만 아동의 개인정보도 수집하지 않습니다.

7. 개인정보 보호책임자

FotData 운영팀 · fotdata.official@gmail.com
